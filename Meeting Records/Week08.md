# User Evaluation Report (Quantitative Analysis)

## **Overview**
As part of our **HCI Evaluation (Part 2: Quantitative Evaluation)**, we conducted user testing with **10 participants**.  
Each participant played the game at **two different difficulty levels (L1 and L2)** and completed both the **System Usability Scale (SUS)** and **NASA Task Load Index (NASA TLX)** after each session.

We used the **Wilcoxon Signed Rank Test** to determine whether there was a significant difference in **perceived workload** and **usability scores** across difficulty levels.

---

## **User Testing Methodology**
1. **Each participant played the game at two difficulty levels (L1 & L2).**
2. **Half of the users** started with L1 and then played L2, while **the other half** did the opposite (L2 → L1) to reduce the learning effect.
3. After each level, participants completed:
   - **System Usability Scale (SUS)** (10 usability ratings, range 1-5)
   - **NASA TLX** (6 workload ratings, range 1-20)
4. **Data was collected and analyzed** to evaluate usability and workload differences.
